# Python Calculator

A beginner-friendly calculator application built using Python and Tkinter.

## Screenshot

![Calculator Screenshot](calculator.png)

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Power
- Modulus
- Square root
- Backspace
- Clear
- Error handling

## Technologies Used

- Python
- Tkinter
